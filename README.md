# GrowthAI

## AI That Works. Systems That Evolve.

GrowthAI is an autonomous AI workforce and business operating system. It is NOT merely a chatbot.

## Core Loop

BUSINESS → OBSERVE → UNDERSTAND → RECOMMEND → BUILD WORKFORCE → APPROVE → PAYMENT → DEPLOY → ACT → VERIFY → MEASURE → OPTIMIZE → EVOLVE

## Quick Start

```bash
# Backend
cd backend
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# Frontend
cd frontend
npm run dev
```

## Environment

Copy `.env.example` to `.env` and fill in required values.
